# HexSoftwares_Animating_Website

## Project Overview
This project was developed as part of **Task 3** for my Web Development Internship at **Hex Softwares**. The goal was to create a modern, high-end website header section featuring complex CSS3 animations with specific time delays to enhance user experience and visual storytelling.

## Features
- **Keyframe Animations:** Custom-built `fadeInUp` and `slideInLeft` animations.
- **Time-Delay Logic:** Staggered entrance for the logo, heading, description, and Call-to-Action button.
- **Modern UI:** A dark-themed, sleek design with a neon glow effect.
- **Responsive Layout:** Optimized for various screen sizes.
- **Interactive Elements:** Glowing text effects and floating background decorations.

## Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Advanced animations, Flexbox layout, and radial gradients.
